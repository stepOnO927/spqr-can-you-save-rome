# Government inquiry identity records

New government inquiries retain the observed English and Chinese names with the dated report, sealed until delivery. Later changes to a person's simulated identity, allegiance, health or existence do not rewrite the government tree or the dossier opened from that report. The dossier uses the reported name and player-held evidence; it does not turn the person into a friendly character merely because their hidden current faction changed.

Introductions, contacts and public professional exchanges also retain the name available when that information was received or observed. Existing historical names can use the fixed historical catalog. An older fictional report that never saved a name is displayed as “Unrecorded name” rather than reconstructed from today's hidden world; it can still be selected and investigated. A newer delivered report can update the current list without changing an older report's snapshot.

This covers the government inquiry tree and dossiers opened from it. Other intelligence and meeting surfaces still need independent audits; this is not a claim that all character information has been snapshotted.

Contacts remain associated with the court where they were established. An employment request to that reported court can be sent without revealing whether the person has since disappeared; the later outcome may lapse. Missing relationship dimensions in older contacts receive neutral defaults instead of being inferred from a foreign person's present secret attributes.
# Roman Senate public records

Opening simulated senators retain their recorded public names; foreign entries are explicitly presented as potentially outdated. An unobserved death, disappearance or rename does not remove a rival's row or replace its name with hidden current data. Older saves recover an opening name only from an unambiguous saved identity claim; otherwise the name remains unrecorded. Requests for a rival senator's endorsement can be dispatched against a stale record and only resolve after two months. The result can lapse without disclosing a hidden cause. The government panel displays the modeled public influence indicator, and inquiry eligibility uses the same value as the action. Actual internal Senate votes continue to depend on simulated conditions; other intelligence surfaces still need separate review.
