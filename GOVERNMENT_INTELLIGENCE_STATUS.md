# Government inquiry identity records

New government inquiries retain the observed English and Chinese names with the dated report, sealed until delivery. Later changes to a person's simulated identity, allegiance, health or existence do not rewrite the government tree or the dossier opened from that report. The dossier uses the reported name and player-held evidence; it does not turn the person into a friendly character merely because their hidden current faction changed.

Introductions, contacts and public professional exchanges also retain the name available when that information was received or observed. Existing historical names can use the fixed historical catalog. An older fictional report that never saved a name is displayed as “Unrecorded name” rather than reconstructed from today's hidden world; it can still be selected and investigated. A newer delivered report can update the current list without changing an older report's snapshot.

This covers the government inquiry tree and dossiers opened from it. Other intelligence and meeting surfaces still need independent audits; this is not a claim that all character information has been snapshotted.
